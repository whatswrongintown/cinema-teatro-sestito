1.4 Vintage poster collection - TODO, proposal
Known: 1,797 images, 3.88 GB, photographed with an iPhone SE (2nd generation),
no copies. Folders by poster size, e.g. folder "fotobuste 50x70" with file
"tt0038338_50x70_01": film code, size, number (different numbers are different
posters of the same film). Some films use local codes instead of IMDb codes.
"tt0047517_70x100_r_01" has "r" for a poster handmade by the owner's grandfather.
Paths in these notes omit extensions; keep real ones.

The owner's poster database is manifesti_archivio.csv (not in the project; inspect
it first). Columns: position, const, title, original_title, year, directos,
location, archivio, locandina_33x70, fotobusta_70x50, manifesto_70x100,
manifesto_100x140, manifesto_140x200, pieghevole, comment, retro. It has one
column per poster format, not one row per image: reshape it into one row per
poster item. Check "retro" (back of the poster) and the "const" values that are
local codes.

Five views of the same collection (no separate copies of the data):
1. By screening year: films screened that year, with all screening dates and
   sources when a film was shown more than once; link to the existing year and
   source pages with real Hugo links. Posters without a matched screening are
   reachable elsewhere and labelled.
2. By film name: alphabetical index with a defined Italian sorting rule; equal
   titles with different film IDs stay separate.
3. By genre: one list per genre, grouped by film; a film may appear in several
   genres; unknown genres are not invented. Keep it separate from the existing
   programming genre pages and link the two where useful.
4. By poster size: an editorial explanation of the physical formats, then a page
   for each format present; keep format and dimensions in separate fields and
   handle unknown sizes explicitly.
5. By film, all versions: every poster image of the film, grouped by size and
   variant, with a handmade label and documented screening dates. A page per
   poster can follow if items need richer notes or shareable links.

Visitor experience: browsable gallery with uncropped thumbnails, title, size and
handmade marker; filters only on reliable metadata; a detail view with a larger
image, description or transcription, real dimensions, attribution and provenance
(unknown kept distinct from confirmed), useful alt text; links to related
screenings and other posters of the same film when the match is verified; a
curated introduction to the grandfather's handmade work.

Catalogue model (validate against the real files):
- Film: film key, titles, optional IMDb ID, release year, genres. Keep local
  codes as they are; never treat them as IMDb IDs.
- Poster item: stable local ID, film link if known, size, variant, handmade
  status, notes, rights status. One film can have several different posters; the
  sequence number is not a count of copies.
- Image: scan linked to its item, with the real relative path and the view
  (front/back); an item can have several scans. Screening dates written on a
  poster are sourced evidence, not confirmed dates.
- Screening: date, film key, recorded title and source from
  programmazione_agende.csv, with the existing methodology caveats.
Keep IDs and file names stable; do not rename, move or overwrite originals
before agreeing a convention; if files are renamed, keep an old-to-new mapping.
Check rights for digitised artwork before publication (ownership of the physical
poster alone may not be enough; the owner confirms all scans can be published).

Source inventory and migration lessons (2026-11-18)
- Inputs: programmazione-agende.csv and programmazione-imdb.csv relative to the
  app working directory. There is no country input. The supplied folder also
  contains deployment metadata; none is required by the native replacement.
- Packages: shiny, ggplot2, ggrepel, dplyr, readr, tidyr, lubridate, scales,
  forcats and DT (called through its namespace). The UI imports a Google font.
  These are legacy dependencies, not packages to install for the replacement;
  prefer the website's local fonts and locally served browser assets.
- The pipeline full-joins entries to IMDb by const/Const, groups by film ID,
  assigns count = 1:n(), keeps count == 1, then sorts by date and drops missing
  sources. Thus it retains the first input row per film, NOT all appearances,
  and NOT necessarily the earliest date if input order changes. The year filter
  is applied afterwards: a later repeat cannot be discovered in its own year.
- Grafici: year selection and chart selection control monthly bars, genre bars,
  or an IMDb rating/vote scatterplot (logarithmic vote axis, film title labels).
  Monthly bars therefore count retained film rows by month, not dated entries;
  with "Tutti" selected they pool those months across years.
- Genre bars first take distinct complete genre strings and only then split
  them. They count genre-label combinations rather than films or entries.
  Both genre and director choice lists split into at most seven components;
  the new exporter should use arrays without an arbitrary seven-value ceiling.
- Riepilogo: retained-row total labelled unique films; highest/lowest IMDb
  scores; director frequency. top_n() includes ties, so a "five" list can exceed
  five rows. There is no minimum-vote rule or explicit tie-break contract.
  Director frequency groups the whole director string, so a co-directing pair
  is a different group from either director individually.
- Tabella: date, recorded title linked to IMDb, directors and genres; DT adds
  its standard table search, ordering and pagination. The year affects every
  tab, but director and genre controls affect only this table. Those two use
  grep(), i.e. regular-expression/substring matching rather than exact
  membership. Do not copy this inconsistent filter scope or regex behavior.
- Release year, runtime, rating and votes are loaded; runtime and release year
  are not displayed in the main table. Original titles, source filtering,
  countries, a year range and persistent filter URLs are not current features.

dashboard_data <- function(project_root = ".") {
  read_data <- function(filename, required) {
    path <- file.path(project_root, "static", "data", filename)
    x <- utils::read.csv(
      path, colClasses = "character", na.strings = c("", "NA"),
      check.names = FALSE, strip.white = TRUE, fill = FALSE,
      comment.char = "", fileEncoding = "UTF-8-BOM"
    )
    missing <- setdiff(required, names(x))
    if (length(missing)) {
      stop("Missing columns in ", filename, ": ", paste(missing, collapse = ", "))
    }
    x
  }
  entries <- read_data("programmazione_agende.csv",
                       c("date", "const", "title", "source"))
  films <- read_data("programmazione_imdb.csv",
                    c("Const", "Title", "Original Title", "Year", "Genres",
                      "Directors", "IMDb Rating", "Num Votes"))
  valid_ids <- function(x) !anyNA(x) && all(nzchar(trimws(x)))
  if (!valid_ids(entries$const) || !valid_ids(films$Const) ||
      anyDuplicated(films$Const)) {
    stop("Missing film IDs or duplicate IMDb IDs.")
  }
  dates <- as.Date(entries$date, format = "%Y-%m-%d")
  if (anyNA(dates) || any(format(dates, "%Y-%m-%d") != entries$date)) {
    stop("Screening dates must be valid YYYY-MM-DD values.")
  }
  unmatched <- setdiff(entries$const, films$Const)
  if (length(unmatched)) {
    stop("Screening film IDs missing from IMDb: ", paste(unmatched, collapse = ", "))
  }
  number <- function(x, field, lower, upper = Inf, integer = FALSE) {
    value <- suppressWarnings(as.numeric(x))
    bad <- !is.na(x) & (is.na(value) | !is.finite(value) |
                        value < lower | value > upper)
    if (integer) bad <- bad | (!is.na(value) & value != floor(value))
    if (any(bad)) stop("Invalid numeric values in ", field)
    value
  }
  list(
    screenings = data.frame(
      date = format(dates, "%Y-%m-%d"),
      screening_year = as.integer(format(dates, "%Y")),
      film_id = entries$const, recorded_title = entries$title,
      source = entries$source
    ),
    films = data.frame(
      film_id = films$Const, title = films$Title,
      original_title = films[["Original Title"]],
      release_year = number(films$Year, "Year", 1, 9999, integer = TRUE),
      genres = films$Genres, directors = films$Directors,
      imdb_rating = number(films[["IMDb Rating"]], "IMDb Rating", 0, 10),
      imdb_votes = number(films[["Num Votes"]], "Num Votes", 0, integer = TRUE)
    )
  )
}

overwrite originals or existing outputs, stops with the affected path on error,
keeps a progress/error report, and uses a new output folder per full run.
