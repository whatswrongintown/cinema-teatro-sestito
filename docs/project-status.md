# Project status

Last review: 2026-11-23. Read this file first and update it whenever a decision
is made. Documentation is in English, site content in Italian. Status words:
TODO / DOING / DONE / DEFERRED, with dates. Assistant rules are in `CLAUDE.md`.

## 1. Project at a glance

- Hugo 0.170.1 Extended, pinned in `netlify.toml`; Netlify runs Hugo only.
  Locally installed with `winget` (package `Hugo.Hugo.Extended`); the old
  blogdown copies in `%APPDATA%\Hugo` were removed on 2026-11-23. On Netlify,
  processed images are cached in Hugo's `cacheDir` (see U01).
  Preview with `hugo server`, build with `hugo`. There is no R, blogdown or
  other build step; R is used only for exploratory analysis outside the repo.
- Historical programming: three CSVs in `static/data/` (5,479 screenings). Hugo
  builds the year, source, genre and country tables, the SVG charts and the
  interactive dashboard from them. Details: `historical-programming.md`.
- Poster collection: `data/posters/films.json` (1,057 films, 1,787 posters)
  and the images in `static/images/manifesti/`. Hugo builds the film and
  letter pages with content adapters. Details: `posters.md`.
- The datasets, the poster data and the poster and source images are final
  (2026-11-23): nothing needs regenerating and `static/images/manifesti/` must
  not be modified.
- Never edit `public/` or `resources/` (generated by Hugo).

## 2. Decisions

- Site content: welcoming, clear, professional Italian. Only the owner
  maintains the site; visitors are mainly locals.
- Keep `params.anno` and the generic favicons (now in `static/images/icons/`). Keep goldmark
  `unsafe: true` (inline HTML).
- Keep Eventi available with its "no events scheduled" message. Only Progetto
  stays in the top menu. No analytics (disabled, Do Not Track respected).
- Contact is a homepage form plus a visible email. Messages are private;
  publishing any needs a separate agreement. Poster scan rights: owner confirmed.
- Netlify plan: Legacy Starter (100 form submissions per site per month; metered
  usage can cause charges). No plan change is proposed.
- Charts: explain their conventions in the methodology; do not recalculate them.
- The social preview images named in front matter `image:` stay as PNG files
  (SVG cannot be used as an Open Graph image).
- Absolute-root URLs and the repeated public email are existing choices, not
  defects. Keep `content/sitemap.md` up to date when sections change.
- 2026-11-23: the project moved from R/blogdown to Hugo only, and from GitHub
  Copilot to Claude Code. The old R scripts, tests and the Shiny app are in Git
  history only.
- 2026-11-23: the owner approved upgrading Hugo, mainly to shorten deploys (see
  U01). Upgraded to 0.170.1: `languageCode` became `locale`,
  `site.Data` became `hugo.Data`, `.Site.LanguageCode` became
  `site.Language.Locale`, and the posters `index` layout became `browse`
  (`index` is reserved by the template system since 0.146). The site uses no
  `excludeFiles`.
