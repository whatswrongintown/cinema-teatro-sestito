# Project status

Last review: 2026-11-23. Read this file first and update it whenever a decision
is made. Documentation is in English, site content in Italian. Status words:
TODO / DOING / DONE / DEFERRED, with dates. Assistant rules are in `CLAUDE.md`.

## 1. Project at a glance

- Hugo 0.136.5 Extended, pinned in `netlify.toml`; Netlify runs Hugo only.
  Preview with `hugo server`, build with `hugo`. There is no R, blogdown or
  other build step; R is used only for exploratory analysis outside the repo.
- Historical programming: three CSVs in `static/data/` (5,479 screenings). Hugo
  builds the year, source, genre and country tables, the SVG charts and the
  interactive dashboard from them. Details: `historical-programming.md`.
- Poster collection: `data/posters/films.json` (1,057 films, 1,787 posters)
  and the images in `static/images/manifesti/`. Hugo builds the film and
  letter pages with content adapters. Details: `posters.md`.
- The datasets, the poster data and the poster and source images are final
  (2026-11-23): nothing needs regenerating and `static/images/manifesti/` must
  not be modified.
- Never edit `public/` or `resources/` (generated by Hugo).

## 2. Decisions

- Site content: welcoming, clear, professional Italian. Only the owner
  maintains the site; visitors are mainly locals.
- Keep `params.anno` and the generic favicons (now in `static/images/icons/`). Keep goldmark
  `unsafe: true` (inline HTML).
- Keep Eventi available with its "no events scheduled" message. Only Progetto
  stays in the top menu. No analytics (disabled, Do Not Track respected).
- Contact is a homepage form plus a visible email. Messages are private;
  publishing any needs a separate agreement. Poster scan rights: owner confirmed.
- Netlify plan: Legacy Starter (100 form submissions per site per month; metered
  usage can cause charges). No plan change is proposed.
- Charts: explain their conventions in the methodology; do not recalculate them.
- The social preview images named in front matter `image:` stay as PNG files
  (SVG cannot be used as an Open Graph image).
- Absolute-root URLs and the repeated public email are existing choices, not
  defects. Keep `content/sitemap.md` up to date when sections change.
- 2026-11-23: the project moved from R/blogdown to Hugo only, and from GitHub
  Copilot to Claude Code. The old R scripts, tests and the Shiny app are in Git
  history only.
- 2026-11-23: the owner approved upgrading Hugo, mainly to shorten deploys (see
  U01). Later versions require `excludeFiles` to become `files` (deprecated
  from 0.153, removed in 0.169) and `languageCode` to become `locale` (from
  0.158); `netlify.toml` must be updated with the version.

## 3. Open items

- **U01 - TODO: upgrade Hugo and shorten the Netlify deploy.** Netlify log of
  2026-11-23: build 5 m 15 s, of which `hugo` takes 287 s; fetching the 1.9 GB
  cache (9 s), deploy (14 s) and the Lighthouse plugin (12 s) are minor. Local
  measurements with Hugo 0.136.5: 92 s with the image cache present, 636 s with
  `--ignoreCache`, so image processing is the dominant cost when the cache is
  missed. The 2,620 processed images are 2 operations (`Fit 1600x1600`,
  `Fill 300x300`, both q50) on about 1,310 images in
  `layouts/shortcodes/image-gallery.html`; the cache is `resources/_gen`
  (669 MB, git-ignored). It is not known whether Netlify's cache restores it
  (the 287 s sits between the warm and cold local times). Options to evaluate,
  with the output compared before and after: make Netlify keep `resources/_gen`
  (a cache plugin; needs approval for the Netlify change), process fewer or
  smaller images, then upgrade Hugo (release notes since 0.136.5, replace the
  deprecated settings above, update `HUGO_VERSION` in `netlify.toml`, check the
  deploy log). A Hugo upgrade alone is not expected to remove the image cost.
- **U02 - DONE 2026-11-23: social-sharing images.** `layouts/partials/social-image.html`
  (called by `head.html`) picks the page's `image:` (a bundle file or an
  absolute path under `static/`), else the nearest ancestor section's, else
  `params.defaultImage`; an `image:` that does not resolve gives a build
  warning. Fixed: archive and article `image:` made bundle-relative (they
  pointed to old blogdown permalinks); year pages use their first chart,
  `proiezioni-mensili.png`, moved to the bundle root; genre and country pages
  dropped `image:` and use the section's (Generi hero, Paesi chart, now
  `content/programmazione-storica/paesi-di-produzione/italia-estero-per-decennio.png`);
  poster film pages get their first poster from the content adapter. Checked
  on a full build: every `og:image` points to a file in `public/`. The static
  cleanup is done: `static/programmazione-storica/` and every `index_files`
  folder are gone.
- No feature roadmap yet: new ideas are agreed with the owner and listed here
  when they are approved.
