# CLAUDE.md

Website of the Cinema Teatro Sestito (San Vito sullo Ionio): its history, archive
documents and historical film programming. Built with Hugo 0.170.1 Extended and
deployed on Netlify, which runs Hugo only.

Read `docs/project-status.md` first: it is the authoritative record of current
state, decisions and open work. The site was migrated from R/blogdown to
Hugo only (2026-11-23). `docs/README.md` indexes the remaining documentation.

## Where changes belong

| Location | Content |
| --- | --- |
| `content/` | pages and articles (manual or generated, check first) |
| `layouts/` | Hugo templates, partials and shortcodes |
| `static/` | assets and source datasets (`static/data/*.csv`); everything here is public |
| `data/` | Hugo data (`data/posters/films.json`, glyph widths for the charts) |
| `docs/` | all project documentation |

Before editing a page, decide whether it is manually written or generated:

- Historical programming pages (years, sources, genres, countries) are ordinary
  Markdown pages ending with `{{% programmazione-tabelle "<mode>" %}}`; Hugo
  builds their tables from `static/data/` (`layouts/partials/programmazione/`).
  Charts are inline SVG from `{{< grafico nome="..." >}}`
  (`layouts/partials/grafici/`). Never paste tables or chart images into the
  pages. The old R generators no longer exist (they would have rewritten the
  pages); see `docs/historical-programming.md`.
- Poster film and title-letter pages are built by Hugo content adapters
  (`content/posters/**/_content.gotmpl`) from `data/posters/films.json`.
  `films.json` and `static/images/manifesti/` are final (see `docs/posters.md`).
- The datasets and poster images are final (2026-11-23): there is no new data
  to regenerate, and `static/images/manifesti/` must not be modified.
- Share cards (link previews): every article needs front matter `image:` (its
  hero and share card); other pages get theirs automatically, cropped to
  1200x630. The main Posters and programming pages use collages made by
  `docs/share-card/make-cards.ps1` (`shareImage:`). Never add other preview
  images. Rules: `docs/design.md`, section "Share cards".

## Never

- Edit `public/` or `resources/` (generated by Hugo).
- Commit private original scans (poster originals, source PDFs) or any local
  working copies of them; only the web images in `static/` are tracked.
- Create duplicate sites, build folders (`public-*`, `build*`, `tmp-*`, ...),
  repository copies or numbered file variants (`index-new.md`, `layout-copy.html`).
  Update files in place; use only `public/` as build output. Any temporary build
  must be removed afterwards.
- Push to `main` without the owner's explicit request: it deploys to production.
- Change Netlify settings without explicit approval.

## Writing

- Site content: Italian, welcoming, clear, professional, historically accurate,
  concise. Keep existing metadata, front matter and terminology.
- Documentation: English, in `docs/`. Keep `README.md` short (purpose, setup,
  build, links). Status words TODO / DOING / DONE / DEFERRED, with dates.

## Development

- Follow Hugo conventions and check APIs against Hugo 0.170.1 (update this
  version here when Hugo is upgraded, see U01 in `docs/project-status.md`). Keep templates
  modular; avoid new dependencies unless clearly justified.
- Documentation is part of every change: update `docs/project-status.md` and the
  relevant guide, remove outdated text, avoid duplicating content between files.

## Local environment (Windows)

- Hugo is on PATH: `hugo server` for preview, `hugo` for a build.
- R is no longer part of the site; it is used only for exploratory analysis of the
  datasets, outside the repository.
- The GitHub CLI (`gh`) is installed and authenticated; use it for GitHub
  operations (PRs, issues) and `git` for commits and pushes against `origin`.

## Before finishing a task

- No generated output edited by hand; changes made at the source.
- No duplicate files or leftover temporary build folders.
- `docs/` updated where the change affects workflow, structure or decisions.
