{{- /* One image resource as a 1200x630 JPEG share card (U17, U18). Every image is cropped to fill the card (the owner preferred crops to whole images on a dark background, 2026-11-26). Images taller than the card keep the band 30% of the way down (like CSS object-position "center 30%"), which on posters, documents and photos usually holds the title, the heading or the faces; Hugo's smart crop picked worse areas. Wider images are cropped at the centre. A JPEG that is already 1200x630 (the section cards made by docs/share-card/make-cards.ps1) is used as it is. Processed images are cached (see netlify.toml). Call with: partial "social-card.html" $imageResource */ -}} {{- $w := 1200 }}{{ $h := 630 -}} {{- if and (eq .Width $w) (eq .Height $h) (eq .MediaType.SubType "jpeg") -}} {{- return . -}} {{- end -}} {{- $img := . -}} {{- $anchor := "center" -}} {{- /* Height of the card's band in source pixels, when the width fills the card. */ -}} {{- $banda := math.Round (div (mul (float .Width) $h) $w) -}} {{- if gt (float .Height) $banda -}} {{- $taglio := int (math.Round (mul 0.3 (sub (float .Height) $banda))) -}} {{- if gt $taglio 0 -}} {{- $img = .Crop (printf "%dx%d bottom" .Width (sub .Height $taglio)) -}} {{- end -}} {{- $anchor = "top" -}} {{- end -}} {{- return $img.Fill (printf "%dx%d %s jpg q82 #14100e" $w $h $anchor) -}}
