{{- /* Opening image of an article: the bundle image named in front matter `image`. When the body starts with that same image (the usual Markdown hero), it is taken out of the body so the page shows it once, and its alt text becomes the caption. Returns dict: img the image resized to at most 1600 px wide (WebP), or false alt the alt text / caption ("" if the body does not start with it) content the rendered body, without the opening image Call with: partial "articoli/apertura.html" . */ -}} {{- $content := .Content -}} {{- $img := false }}{{ $alt := "" -}} {{- with .Params.image -}} {{- $src := . -}} {{- with $.Resources.Get $src -}} {{- $img = . -}} {{- if and (eq .ResourceType "image") (ne .MediaType.SubType "svg") (gt .Width 1600) }}{{ $img = .Resize "1600x webp q80" }}{{ else if eq .MediaType.SubType "png" }}{{ $img = .Resize (printf "%dx webp q80" .Width) }}{{ end -}} {{- end -}} {{- $re := printf `^\s*

]*>\s*

` (replaceRE `([.\[\]()*+?^$|{}\\])` `\$1` $src) -}} {{- with findRESubmatch $re $content 1 -}} {{- $alt = index (index . 0) 1 | htmlUnescape -}} {{- $content = replaceRE $re "" $content 1 | safeHTML -}} {{- end -}} {{- end -}} {{- return dict "img" $img "alt" $alt "content" $content -}}
